# HomeCenter
HomeCenter est un projet personnel pour centraliser les données du fonctionnement d'un foyer.
Basé sur Raspberry Pi 3 B+ / Carte SD 64 Go / OS Raspberry 64 bit
Périphériques :
- Freenove touch screen
- Scanner code barre
- Capteurs (température, ...)

Conception d'une application avec interface graphique et navigation via écran tactile

Fonctionnalités prévues :
- Météo de la journée et suivi maison
- Agenda
- Enregistrement des courses, alertes sur les produits à date, suggestions de recettes, retrait des produits consommées
- To do
- Prévision des dépenses (électricité, charges récurrentes, ...)

L'objectif principal est de centraliser sur une seule interface.
